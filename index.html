공정 DX · 2026 · 단독 수행
Case Study · Question

"작업 실수를 사람의 주의력이 아니라
구조로 막을 수 없을까?"

Before — 종이 작업지도서
  • 주의사항을 지나쳐도 아무도 모름 — 유사 부품 오조립 등 반복 이력
  • 시험 결과·자재번호를 수기로 옮겨 적음 (누락·오기 위험)
  • 문서가 개정되면 어떤 화면·기록이 낡았는지 추적 곤란
→
After — 디지털 작업지도서
  • 주의 스텝은 확인 체크 전 다음 진행이 잠김 (게이트)
  • 조립→시험→기록 한 화면 — 기입값이 공식 기록 양식에 자동 반영
  • 개정 문서를 재변환만 하면 자동 추적 + 스스로 검증
1불량 이력 분석으로 문제 정의 — 품질 기록에서 반복 실수 유형을 도출하고, 잠금을 걸 지점을 데이터로 선정
2원칙 수립 — 공식 문서가 유일한 원천(임의 삽입 금지) · 무상태(기록은 PDF 서명으로 완결) · 애매하면 멈추고 사람에게 묻기
3자동 변환 파이프라인 — 문서 자동화로 표를 파싱 → 스키마 검증 → 클릭 진행형 웹 화면 생성. 같은 문서면 항상 같은 결과(결정적)
4매칭 레지스트리 — 기입 칸·기록 좌표를 순번이 아닌 내용(문구·파일명) 키로 연결 → 문서 개정으로 순서가 밀려도 자동 추적, 애매한 건은 사람이 1클릭 확정하면 이후 자동
5자기 검증 내장 — 생성 직후 산출물을 원본과 전 항목 자동 대조, 하나라도 불일치면 생성 실패 처리 + 불량본 격리

빛반사 결함 합성기

머신비전 · 합성 데이터 · 단독 수행
Case Study · Question

"결함 사진이 21장뿐인데,
결함 검출 AI를 어떻게 학습시키지?"

Before — 데이터 부족
  • 시약 표면 빛반사 결함의 실물 사진이 극소수 (현장 발생을 기다리는 것 외 수집 불가)
  • 수집해도 정답 라벨(bbox)은 일일이 수작업
  • 결함 강도별 분포 제어 불가
→
After — 합성 데이터 생성기
  • 정상 제품 사진 1장 → 사실적 결함 이미지 무제한 생성
  • 합성 위치 기반 GT bbox 라벨 100% 자동
  • 결함 강도 5단계·분포를 수치로 제어
1제품 기하를 수식으로 모델링 — 렌즈 왜곡(fisheye)이 있는 다중 웰 배열을 평면 격자가 아닌 파라메트릭 곡면 그리드로 기술 → 어떤 사진에도 마스크 정합
2실물 패치 + AI 생성 병행 — 부족한 실물 패치를 AI 생성으로 보강하되, 모양 필터(장단비·채움률)로 실물과 다른 형태를 자동 차단
3"붙여넣기"가 아니라 "빛을 더하는" 합성 — 불투명 합성은 가짜 티가 남 → screen 블렌딩으로 바닥 텍스처를 살리며 밝기만 추가, 반사 코어는 하이라이트로 포화
4실패 → 진단 → 개선의 반복 — "반사가 구름처럼 뭉개짐" 같은 문제를 원인(과도한 페더링·업스케일)까지 파고들어 엔진을 v1→v4로 6차례 개선
5누구나 쓰는 3단계 위저드 앱 — 마스크 정합 → 분포 설정 → 배치 생성. 미리보기와 실제 출력이 같은 엔진을 거치게 설계 (미리보기 = 결과 보장)
