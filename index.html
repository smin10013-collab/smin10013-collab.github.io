Project 01 · Deterministic Pipeline
운에 맡기지 않는 변환 — 같은 문서면 항상 같은 화면이 나오고, 원본과 다르면 생성이 차단됩니다.
pipeline — deterministic
# 같은 입력이면 항상 같은 출력 — 운에 맡기지 않는다
steps = parse_doc(source)      # 표 → 스텝 (규칙 기반)
validate(steps, schema)       # 위반 = 등록 거부
html  = render(steps, template)
diff  = self_check(html, steps) # 생성물-원본 전수 대조
if diff: reject(html)         # 불일치 = 생성 차단
1
파싱 — 규칙 기반
구형 .doc는 라이브러리로 못 읽어 Word 자체를 자동화(COM)해 표 구조를 스텝 JSON으로 추출. 모호한 표는 조용히 넘기지 않고 멈춰서 보고
2
매칭 — 내용 키
확인 팝업은 스텝 번호가 아니라 내용(공정명·부품번호) 키로 부착 — 문서가 개정돼 번호가 밀려도 자동 추적
3
렌더 — 템플릿 1벌
화면 템플릿은 단 하나, JSON만 주입해 단일 HTML 생성 — 어떤 문서든 화면·게이트 동작이 동일, 오프라인 실행
4
자기 검증 — 틀리면 차단
생성된 화면을 되읽어 원본과 전수 대조(578항목), 불일치면 생성 차단. 오류를 일부러 주입해 검증기 자체도 검증

Project 02 · Light, not Paste
불투명한 '붙여넣기'가 아니라 빛을 더하는 합성 — 바닥의 액체 텍스처를 살린 채 반사만 얹습니다.
synth — light, not paste
# '붙여넣기'가 아니라 '빛을 더하는' 합성
mask  = fit_parametric_grid(img)   # 렌즈 왜곡 수식화
patch = pick(streak_only(library)) # 모양 필터 통과분만
alpha = edge_feather(core_only(patch))
out   = screen_blend(img, patch, alpha)
label = bbox_of(placement)         # GT 자동
1
기하 정합 — 왜곡 수식화
렌즈가 휘게 찍은 만큼 그리드도 휘도록 fisheye 곡면을 파라미터로 기술 — well 하나하나에 정확히 좌표를 맞춤
2
재료 검증 — 모양 필터

3
빛 합성 — screen 블렌드
불투명 붙여넣기 대신 밝기만 더하는 합성 — 코어는 255 하이라이트로 살리고, 가장자리 밴드만 페더
